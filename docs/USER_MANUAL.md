# دليل المستخدم (End-User Manual) — منصة مُحكَم (Muhkam `v1.1.1`)

> **نطاق Supabase في هذه الحزمة:** الكود ومخطط SQL فقط. استُبعد ملف صفوف المعرفة `database/03-bayyena_knowledge_rows.sql` من ملفات المصدر الحالية وتاريخ Git؛ أي وصف قديم لـ141 مقطعًا يخص نسخة سابقة ولا يعني أن صفوف البيانات موجودة في هذا التسليم؛ أي وصف قديم لـ141 مقطعًا يخص المصدر السابق وليس بيانات موجودة في هذا التسليم. أُحدث اختبار جرد الملفات ليؤكد وجود ملفات SQL الثلاثة وغياب صفوف البيانات، ولم يُحذف أو يُخفف أي اختبار وظيفي أو XSS.


> **تحديث توثيق التسليم:** الاسم الحالي للمساعد هو «محكم». المعرف `bayyena_knowledge` تقني داخلي. هذه لقطة المصدر v1.1.1، وليست نسخة مثبتة التطابق مع النشر الحالي. البحث معطّل في كود هذه اللقطة؛ مفاتيحه مفعّلة في الموقع الحي وتؤكد المالكة عمله، ولم يُرسل استعلام مستقل في المراجعة. لا يُعد فرق النسخة عطلًا حيًا. ملف `database/01-schema.sql` مسودة مُعاد بناؤها بأنواع وسياسات مستنتجة، وليس مخطط Supabase معتمدًا؛ لا يُنفذ على قاعدة حية قبل المقارنة واعتماد المالك. تعريفات CI/النشر ملفات مصدر، لا دليل تشغيل سحابي.


مرحباً بك في **مُحكَم (Muhkam)**، المنصة القانونية الذكية المتخصصة في القانون المصري، والتي تقدم **أربع خدمات أساسية** (**مراجعة العقود**، **صياغة العقود**، **البحث القانوني**، **ترجمة العقود**) بالإضافة إلى **المساعد القانوني الذكي «محكم» (Muhkam RAG Assistant)**، عبر **ثمانية مسارات عمل (8 n8n Workflows)** متكاملة.

- **رابط المنصة المباشر:** https://mohakem-contract-platform.vercel.app/
- **تنبيه النسخة التجريبية الأكاديمية:** هذه المنصة مخصصة للعرض والتجربة الأكاديمية فقط؛ يُرجى **عدم رفع أي أسماء أو أرقام قومية أو عناوين أو بيانات شخصية حقيقية**، واستخدام بيانات تجريبية فقط.

## 1. البدء السريع وتسجيل الدخول (Authentication)
1. افتح الرابط المباشر للمنصة: `https://mohakem-contract-platform.vercel.app/` (أو افتح ملف `index.html` محلياً).
2. اضغط على زر **تسجيل الدخول** في الشريط العلوي، واختر **حساب جديد** لإنشاء حساب تجريبي بعد الاطلاع على **سياسة الخصوصية وشروط الاستخدام** والموافقة عليها.
3. يمكنك التبديل في أي وقت بين **خمس لوحات لونية (تشمل الوضع النهاري والليلي Light / Dark Mode)** وبين **اللغة العربية والإنجليزية (AR / EN)** من الشريط العلوي.

## 2. الخدمات الأربع الأساسية (The Four Core Services)

### الخدمة الأولى: مراجعة العقود القانونية (Contract Review)
تتيح لك هذه الخدمة فحص عقودك (**عقد إيجار سكني بين الأفراد** أو **عقد بيع سيارة بين الأفراد**) واكتشاف الثغرات والمخاطر القانونية:
1. اختر تبويب **مراجعة عقد**.
2. حدد **صفتك** (المستأجر / المؤجر / المشتري / البائع)، و**نوع العقد** (إيجار سكني / بيع سيارة)، و**حالة العقد** (لم أوقّع بعد / وقّعت بالفعل).
3. ارفع ملف العقد بصيغة **PDF** (رقمي أو مصوّر عبر المسح الضوئي OCR)، أو **DOCX**، أو **TXT**، أو صورة (حتى 20 ميجابايت)، أو الصق نص العقد مباشرة.
4. اضغط على **ابدأ مراجعة العقد**.
5. يقوم النظام باستخراج البنود ومطابقتها مع القواعد القانونية المصرية الحاكمة لنوع العقد:
   - **عقود الإيجار السكني الجديدة بين الأفراد:** تخضع لأحكام **القانون المدني المصري (المواد 558 وما بعدها)** و**القانون رقم 4 لسنة 1996** واتفاق الطرفين (*ملاحظة قانونية هامة: القانون رقم 164 لسنة 2025 ينظم عقود الإيجار القديم فقط الخاضعة للقانونين 49/1977 و136/1981، ولا يُعد أساساً لعقد إيجار سكني جديد*).
   - **عقود بيع السيارات المستعملة بين فردين غير محترفين:** تخضع لأحكام البيع وضمان التعرض والاستحقاق وضمان العيوب الخفية في **القانون المدني المصري (المواد 418 و447 وما بعدها)** و**قانون المرور رقم 66 لسنة 1973 وتعديلاته** (*ملاحظة قانونية هامة: قانون حماية المستهلك رقم 181 لسنة 2018 لا يحكم بيع سيارة مستعملة بين فردين غير محترفين*).
6. يعرض النظام تقريراً شاملاً يتضمن المخاطر مرتبة حسب الخطورة، وسبب كل خطر، وأثره العملي، والتعديل المقترح للتفاوض (أو الإجراء العملي بعد التوقيع).

### الخدمة الثانية: صياغة العقود الذكية (Contract Drafting)
1. انتقل إلى تبويب **صياغة عقد**.
2. اختر نوع العقد المطلوب (**عقد إيجار سكني** أو **عقد بيع سيارة**).
3. أدخل بيانات تجريبية للطرف الأول والطرف الثاني، والبيانات الجوهرية للعقد (مثل عنوان العقار، القيمة الإيجارية، التأمين، المدة، أو بيانات السيارة ورقم الشاسيه والموتور والثمن، والشرط الجزائي والمحكمة المختصة).
4. اضغط على **إرسال**؛ يقوم المسار `03-contract-drafting` باستدعاء مسار البحث القانوني (`04-legal-research`) آلياً واسترجاع النماذج القياسية وصياغة مسودة عقد متكاملة ومراجعتها ذاتياً.

### الخدمة الثالثة: البحث القانوني المؤصّل (Legal Research)
1. اختر تبويب **بحث قانوني**.
2. اكتب سؤالك القانوني، وحدد **نوع العقد محل الاستشارة** و**صفة السائل**.
3. يقوم النظام بتصنيف الاستشارة، والبحث في النصوص التشريعية المصرية، وتقديم مذكرة قانونية مسببة ومؤصّلة بأرقام المواد القانونية مع تقييم درجة الثقة.

### الخدمة الرابعة: ترجمة العقود القانونية (Hybrid Legal Contract Translator)
1. اختر تبويب **ترجمة عقد**.
2. ارفع ملف العقد (PDF / DOCX / TXT) أو الصق النص، وحدد اتجاه الترجمة (**من العربية إلى الإنجليزية** أو **من الإنجليزية إلى العربية**).
3. يعتمد النظام على **قاموس المصطلحات القانونية المصرية** المدمج مع الذكاء الاصطناعي، ويقوم بمراجعة الأرقام والتواريخ والمبالغ المالية وأرقام الشاسيه (`Validate Numbers & Align Clauses`) لضمان التطابق التام بين النص الأصلي والمترجم.

## 3. المساعد القانوني الذكي «محكم» (Muhkam RAG Assistant)
1. من قسم **اسأل المساعد القانوني** (أو عبر الزر العائم 💬 أسفل الشاشة)، يمكنك طرح أي سؤال قانوني باللغة العربية أو الإنجليزية.
2. حدد **أسلوب الإجابة** (**مبسّط للشخص العادي** أو **مهني للقانوني**) و**نوع السؤال** (**سؤال عن عقد** أو **بحث قانوني**).
3. يستخدم تصميم المساعد قاعدة معرفة متجهة باسم `bayyena_knowledge` ويستطيع إظهار مصادر مع الإجابة. فحص metadata الحي أثبت وجود الجدول وبنية المتجه والفهرس، لكنه لم يقرأ صفوفًا أو يقس عددها أو يتحقق من مصدرها؛ لذلك لا يُعتمد هنا رقم تاريخي مثل 141 كمحتوى حي؛ لم تُقرأ صفوف المعرفة.

## 4. البحث الخارجي، السجل، والدعم الفني
- **البحث الخارجي (`08-web-search.json`):** مفاتيح البحث ظاهرة ومفعّلة في الواجهة الحية، وتؤكد المالكة أن الميزة تعمل. لم يُرسل استعلام مستقل في هذه المراجعة. أرشيف المصدر v1.1.1 أقدم ويعطّل المفاتيح فيه؛ لا يُعد ذلك دليلًا على تعطّل البحث الحي ولا يجوز تعميم إعداد الأرشيف على النشر الحالي.
- **سجلّي (History):** تُظهر بنية Supabase المرصودة سياسات RLS مقيّدة بهوية المستخدم لسجل history؛ لكن العزل لم يُختبر بجلسات حية متعددة، فلا تعتمد على هذا الوصف كاختبار تشغيلي. استعرض عناصر حسابك أو احذفها يدويًا بعد التحقق من الخدمة (لا يتم تشغيل الحذف التلقائي بعد 30 يوماً إلا بموافقة صريحة من مالك قاعدة البيانات).
- **الدعم الفني (Support Desk):** يمكنك إرسال تذكرة دعم فني من قسم **الدعم**؛ يرفق النظام بيانات تشخيصية تقنية مبسطة ويوجهها عبر المسار `01-support-desk.json`.
- **فحص حالة الاتصال (`#diag`):** بإضافة `#diag` إلى نهاية رابط الموقع في المتصفح (`https://mohakem-contract-platform.vercel.app/#diag`)، تظهر لوحة تشخيص فورية تفحص استجابة جميع مسارات n8n.
